# Layers 1–2 protocol v2 — 8 October 2026


This is a **design change made after observing the failed G2 fits, quasi-separation and calibration results**. It is not a pre-results repair of protocol v1 and is not a confirmatory replication. The old results are not targets to reproduce or improve. Authority is Hakan's explicit G2-bis instruction. Protocol v1, A2, all G2 aggregate artifacts and private source/model artifacts remain unchanged; the appended decisions preserve the earlier text in `docs/versions/DECISIONS_G2_2026-10-08.md`. The pre-amendment public/private hash ledger is `docs/G2_FROZEN_HASHES_2026-10-08.json`.

The executable choices in `config/g2_bis_2026-10-08.yaml` and detailed protocol in `docs/PROTOCOL_v2_2026-10-08.md` are committed **before the first refit**. Both remain fixed during G2-bis. No performance, significance or adverse-loss direction determines model choices.

1. **Estimators and comparability.** Firth-penalized binomial logit is primary in the five existing Layer 1/2 no-Term, with-Term and peak-path specifications. All primary models stay Term-free; with-Term is a qualified sensitivity. Each corresponding unpenalized logit uses exactly the same rows and reduced design columns. Failed MLE coefficients and predictions are not valid estimates and will not enter results. Exclude InitialInterestRate from the shared specifications because its historical missingness prevents comparability; report missingness for 1991–2002 and 1991–2009. Existing ElasticNet/LightGBM hyperparameters and selected boosting rounds are copied from hashed G2 Layer 1 checkpoints, without any new selection, early stopping or tuning.
2. **Outcome-independent pooling and rank.** Fit separate Layer 1 (1991–2002) and Layer 2 (1991–2009) level maps. Every categorical variable except ProjectState maps training levels with count/n strictly below 0.001 to Other. Missing values are normalized to __missing__ first and face the same training-frequency rule. States are never pooled or mixed with divisions. For unseen nonstate levels, use observed Other if present; otherwise encode no unsupported dummy and disclose the zero-dummy/reference-equivalent fallback and its counts. Numeric median imputation, missing flags and standardization use only layer estimation rows. Drop train-constant/exactly redundant columns using the fixed train-only rank tolerance, not outcomes; retain supported state fixed effects. Export original-to-pooled counts, resulting level event/non-event counts, references, dropped columns, rank and separation diagnostics. Freeze those artifacts before the first bootstrap attempt.
3. **Weighted Firth objective and numerical criteria.** Maximize sum_i w_i[y_i eta_i−log(1+exp(eta_i))] + 0.5 log det{X' diag(w_i p_i(1−p_i))X}. Unit observation weights define point estimates, with no class balancing, oversampling, intercept correction or primary recalibration. Use adjusted-score Fisher scoring/IRLS with maximum 100 iterations, maximum coefficient step 5, at most 25 step halvings, and absolute likelihood-change, score and coefficient-change tolerances each 1e−5. Nonfinite quantities, nonpositive-definite information, information condition above 1e14, line-search exhaustion or iteration exhaustion are recorded failures. Start point fits with an empirical-logit intercept; draw fits start at the corresponding unit-weight estimate. Validate weighted likelihood/score against analytic cases, finite differences, replication equivalence and an independent established implementation before empirical fits. No numerical tolerance is relaxed after results.
4. **199 positive state-weighted multiplier attempts.** Seed 20261008; generate one independent Exp(1) multiplier for each sorted training state per attempt. Reuse the same underlying 51-state draws across layers/specifications and paired scenarios. Normalize within each sample so weighted loan count equals the original count; every state remains present. Re-estimate weighted Firth in every attempt. Hold maps, preprocessing, design, evaluation/reference loans, LGD and paths fixed. Use successful fully defined draws only for 95% linear-interpolated percentile intervals, with attempted/successful/failed counts and per-estimate denominators; fewer than two successful values means unavailable intervals. Never redraw failures or enlarge 199 after inspection. Intervals for coefficients, average marginal associations and stress PD/EL are labelled re-estimated training-state multiplier intervals; paired loss differences use the same draw. State clusters are assumed independent. These intervals exclude source-vintage, LGD, calibration-model, portfolio and scenario-path uncertainty. Retained 999-draw evaluation intervals condition on a fitted model and are labelled separately.
5. **Chronology, calibration and validation.** Layer 1 keeps 1991–2002 estimation, 2003H2 benchmark sigmoid calibration, 2007–2009 crisis evaluation and 2011–2013 additional check. Firth remains raw; calibration intercept/slope and bins are diagnostics only. Layer 2 estimates on 1991–2009, uses frozen corresponding Layer 1 G2 LightGBM parameters/rounds, calibrates those trees on 2010 only and checks 2013–2014. Every Layer 2 output states “Retrospective conditional validation using realized macro paths.” Training labels mature by end-2012; 2010 calibration labels extend through end-2013, overlapping the 2013 validation calendar; 2013 already entered G2 later-cohort evaluation, so this is post-amendment validation, not a previously untouched confirmatory test. No held-out outcome determines fitting, calibration or reporting thresholds. Report raw/calibrated trees separately, and fitted-cohort diagnostics separately from held-out performance.
6. **Sources and fixed losses.** Preserve frozen loans/BLS/FHFA files and observations. Acquire only missing direct BLS 2017 observations in new dated files; verify all unemployment months and HPI quarters required for every cohort through 2017. A new source manifest records hashes, retrieval dates and revised-vintage qualifications. No FRED, general macro refresh or loan replacement. Keep the v1 primary/capped and A2 downturn LGD rules and the exact 2006 portfolio/scenario paths. The 2006 portfolio enters expanded Layer 2 estimation; it is a fixed scenario portfolio, not an out-of-sample performance test. Univariate state-specific and pooled-global support checks report counts, fractions and approval exposure, without asserting joint support. Every loss table carries the complete EAD/LGD/pro-rata assumption label. The old-extract CCF sensitivity stays unavailable unless its existing admissibility requirements are met; no new extract acquisition is authorized here.
7. **Term timing audit.** Use all applicable eligible CHGOFF/PIF rows, including events after the 36-month outcome window. Define elapsed months as actual elapsed days/(365.25/12), consistently for both event types. Valid reported Term is finite and strictly positive; retain missing/invalid counts. Export distributions by approval year and loan type and the absolute-difference ≤3-month share. Approval-time verification requires supporting metadata/original-vintage evidence. As a descriptive flag for strong later-update evidence, require at least 100 date/term-valid charge-offs and ≥50% matching within three months; PIF matching alone and a low matching share cannot establish an approval-time vintage. Otherwise report timing unverifiable. This convention/flag is fixed before audit results; primary models exclude Term regardless.
8. **Execution boundary and reporting.** After this protocol commit, run a bounded timing/memory pilot covering unit estimates and the first five scheduled attempts per specification. Those five remain within the fixed 199; no restarts/redraws. The pilot bound is 30 minutes and 6 GiB process RSS; if exceeded, preserve completed attempts and report the limitation rather than silently revise computation/specification. Report projected runtime before continuing the remaining attempts. Use only new `results/g2-bis-2026-10-08/`, private dated data/model directories and `docs/G2_BIS_REPORT_2026-10-08.md`. Report failures and G2-to-G2-bis changes separating estimator/design changes from estimation-cohort/calibration changes. Local commits only; stop at G2-bis. G3/G5, publication, pushes and paid calls remain prohibited.
